Week 1 · Beginner Python

Hello, Python! 👋

We start super easy. No complicated stuff yet. Just: what IS Python, how do you run it, and how do you make it say things. That's literally it this week.

🎯 Week Goals

  • Know what Python is
  • Run your first line of code
  • Use print() to show text
  • Write comments with #
  • Know what a syntax error looks like

🧑‍🏫 Teacher Notes

Week 1 is 100% about confidence. If he types one line and sees it work — that's the whole win. Don't rush.

💡Use replit.com — no install, just open the browser and start typing. Remove all friction this first week.
1 What Is Python?

Python is a programming language. You type commands, and the computer follows them — like a very obedient robot. 🤖

Python is one of the easiest languages to start with. It reads almost like English.

🌍Python is used for websites, games, AI, automation... but none of that matters yet. Right now we're just learning to talk to it.
2 Your First Line of Code

The first thing everyone learns: print() — it shows text on screen.

print("Hello, World!") print("My name is Dara") print("I am learning Python!")
🤔 What does print("Hi!") show on screen?
3 Comments — Notes for Humans

A comment starts with #. Python completely ignores it.

# This is a comment. Python skips this. print("This actually runs") # can go at end too
4 Syntax Errors
print("Hello") # ✅ correct print "Hello" # ❌ missing () — SyntaxError
💡Tell him to break the code on purpose and read the error. Getting comfortable with errors early = huge confidence boost.

🚀 Week 1 Quest: Introduce Yourself

Write a program that introduces you using multiple print() lines and at least 2 comments.

  • Print your name
  • Print your age
  • Print your favourite thing
  • Print one weird fun fact
  • Add at least 2 comments

Week 2 · Beginner Python

Variables & Data Types 📦

Python needs to remember things. Variables are labelled boxes where you store information. This week Python gets a memory!

🎯 Week Goals

  • Create and use variables
  • Know the 4 main data types
  • Use type() to check types
  • Use input() to get user data
  • Print variables in sentences

🧑‍🏫 Teacher Notes

Draw a box on paper before touching code. Label the outside "name", write "Dara" inside. That's a variable. Make it physical first.

💡Ask: "If Python forgot everything each time, how would it remember your name?" Let him figure out why variables exist.
1 What is a Variable?
name = "Dara" # text age = 15 # whole number score = 98.5 # decimal print(name)
🤔 After x = 5 then x = 10, what does print(x) show?
2 The 4 Main Data Types
📝

str

Text / words

"Hello"
🔢

int

Whole numbers

15, -3, 100
🔣

float

Decimal numbers

4.99, 3.14
✅

bool

True or False

True / False
3 Getting Input
name = input("What is your name? ") print("Hello, " + name)
⚠️input() always gives back text (str) — even if the user types a number. We fix that in Week 3!

🚀 Week 2 Quest: Profile Card

  • Store name, age, favourite food, favourite game in variables
  • Use input() to ask for at least one of them
  • Print everything in a nice readable way
  • Use type() to check each variable's type

Week 3 · Beginner Python

Operators & Expressions ➕

Python can do all your maths. This week we make it calculate things — and learn the habit of predicting output BEFORE running code.

🎯 Week Goals

  • Use + − * / operators
  • Know order of operations
  • Combine text + numbers with str()
  • Convert input with int()
  • Predict output before running

🧑‍🏫 Teacher Notes

Before EVERY code block, ask him to write the expected output on paper first. The prediction habit matters more than getting the right answer.

💡If he guesses wrong, don't correct immediately. Ask "Why did you think that?" Then run it and let the result teach him.
1 The 4 Math Operators
+

Add

Same as always

−

Subtract

Find the diff

*

Multiply

Use * not ×

/

Divide

Use / not ÷

🤔 What does print(7 * 3) output?
2 Order of Operations
result = 10 + 5 * 2 # 20, NOT 30! fixed = (10 + 5) * 2 # brackets → 30
🧠 5 + 3 * 2 = ?
3 Text + Numbers + input()
age = 15 print("I am " + str(age)) # ✅ works print("I am " + age) # ❌ crash! num = int(input("Enter a number: ")) print(num + 10)
🤔 User types "7". What does int(input()) + 10 print?

🚀 Week 3 Quest: Simple Calculator

  • Ask for first number, then second number
  • Convert both with int()
  • Print: Addition, Subtraction, Multiplication, Division
